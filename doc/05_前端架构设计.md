# 前端架构设计

## 前端技术栈

前端使用 Vue 3 Composition API 和 TypeScript，Vite 负责开发服务和构建。Element Plus 提供表单与表格组件，Pinia 管理共享状态，Vue Router 管理页面，Axios 访问 API，vue-i18n 提供多语言支持。地图使用 Leaflet，灰线计算使用 SunCalc。

Electron 与 Capacitor 共用这套页面代码，具体运行条件见 [Windows 与 Android 部署](09_Windows与Android部署.md)。数据库读写由 FastAPI 完成，前端不直接访问 SQLite。

## 核心页面设计

### 1. 认证流程

`LoginView.vue` 和 `RegisterView.vue` 调用 `auth` store。登录后把 access token 与用户对象存入 localStorage 的 `token`、`user`；没有 refresh token。两种模式登出时都先请求服务器撤销会话，成功或已过期后清除本地状态并跳转 `/login`；网络失败会显示错误。

业务请求返回 401 时只清除本地会话，不再调用登出接口。WebSocket URL 不携带 JWT，连接后发送首条 `{"token":"..."}`；4401 表示会话失效。路由守卫只负责导航，实际认证由后端完成。

### 2. 仪表板（DashboardView.vue）

仪表板展示 UTC 时钟、用户时区时钟、QSO 概览、最近日志、DXCC 进度、波段与模式分布，以及快捷入口。比赛日历使用页面内置数据。

概览可按激活台站请求；波段和模式分布统计当前用户全部日志。

### 3. 日志管理（LogsView.vue）

日志列表由 `logs` store 保存分页、排序和筛选条件。筛选包括日期、呼号、波段、模式、台站、网格和 DXCC；页面初始化时应用激活台站筛选，并读取 URL 中的 `grid`、`dxcc`、`band` 参数。

新增日志使用对话框，无台站时主操作直接进入“添加台站”。导入对话框先选目标台站，缺少台站或文件时不能提交；发生数据库批次失败时保留已提交计数，并阻止直接重复提交同一文件。导出范围由台站与本网格选择器确定；文件请求完成后关闭弹窗，失败时保留弹窗并显示原因。导入超时 120 秒，导出用原生 `fetch` 获取 Blob。

列表上的 UDP 按钮控制后端监听并接收 `qso_received` 消息。收到消息后刷新列表并显示提示；日志保存需要用户确认。

### 4. 台站与位置管理（StationsView.vue）

树形界面按“台站 → 位置”展示数据。台站仅包含呼号；网格、电台、天线、高度和 QTH 属于位置。激活位置通过后端接口取消该用户其他位置的激活状态。

删除台站会影响其日志和位置，删除位置只软删除位置。删除规则见[数据库文档](02_数据库设计说明.md)。

### 5. 呼号查询（CallsignSearchView.vue）

输入呼号后请求后端，显示姓名、实体、网格、坐标、执照及 QRZ 链接，并标注缓存或离线来源。离线结果只用于推断实体。

### 6. DX Cluster 实时 Spot（DXClusterView.vue）

页面选择节点，通过 REST 连接和断开后端 Telnet 连接，通过 WebSocket 接收历史和实时 spot。连接状态、节点、spot 列表由 `dxcluster` store 管理；显示缓冲最多 200 条。

浏览器 WebSocket 断线后最多尝试 5 次退避重连，间隔上限 16 秒。重连只恢复浏览器到后端的通道，Telnet 节点连接由后端管理。

### 7. 梅登网格地图（MapView.vue）

地图使用 OpenStreetMap 底图，叠加梅登网格热度、从本台位置出发的放射线及灰线图层。点击网格可跳转日志页筛选对方网格。地图数据默认按激活位置的本网格筛选，具体口径见[API 端点说明](04_API端点说明.md)。

底图需要网络访问；日志和网格统计来自数据库。

### 8. 工具箱（ToolsView.vue）

`views/tools/components/` 包含 `FreqWavelengthTool`、`DipoleTool`、`VerticalTool`、`SwrTool`、`LcFilterTool` 和 `GeneralTools`。计算在前端完成；输入、单位、天线图和结果为主要引导，公式与来源放入默认折叠的“公式”参考，不影响正常计算。

### 9. 回收站（RecycleBinView.vue）

页面调用 `recycleApi` 展示 7 天保留期内的日志备份，用到期状态和恢复按钮引导操作。清空前会进行一次不可撤销确认。列表中的 ID 是回收站条目 ID；清空或删除条目不会物理删除原 QSO。

### 10. 快捷链接（ShortcutsView.vue）

页面展示内置网站和自定义链接。自定义链接保存在后端进程内存。创建端点使用查询参数。

### 11. 统计分析（AnalysisView.vue）

页面使用波段/模式分布、DXCC 实体×波段图表和波段×模式矩阵。点击图表可把 `dxcc`、`band` 等条件传给日志页。DXCC 实体选择数据来自 `data/dxcc-entities.json`。

### 12. 设置（SettingsView.vue）

设置包含语言、时区、主题、改密、后端模式与 SQLite 路径信息，以及 UDP 设置和服务器模式的注销入口。语言可即时切换；保存偏好通过 `PATCH /auth/me` 更新后端，再更新 store 和本地用户缓存。

UDP 端口使用 1024～65535 的整数控件，越界输入在失焦时修正为边界值，界面值与启动请求一致；端口相同、无效或缺失时禁用“应用并启动”。只有当前账户可操作的主机级控制会显示；MySQL 普通用户仅能查看 DX spot。跨设备 UDP 配置见部署文档。

不可撤销删除、导入中断后保留已保存记录、注销冷静期等操作会在界面中提示。参数错误和偏好保存失败会显示具体原因。

### 13. 管理后台（views/admin/）

`UsersView.vue` 管理用户；`SystemView.vue` 显示系统状态和配置；`AuditLogView.vue` 查询审计。入口受数据库模式与角色控制，实际权限仍由后端认证依赖检查。

## 状态管理（Pinia Store）

| Store | 主要状态与操作 |
| --- | --- |
| `useAuthStore`，`auth.ts` | 用户、令牌、数据库模式；注册、登录、登出、取当前用户、取模式 |
| `useLogsStore`，`logs.ts` | 日志、台站、激活台站、分页、筛选和排序；CRUD 与刷新 |
| `useStatsStore`，`stats.ts` | 概览、波段、模式、DXCC 图表和交叉矩阵 |
| `useDxClusterStore`，`dxcluster.ts` | 节点、连接状态、spot、WebSocket 与重连定时器 |

日志查询使用递增请求 ID，只接收最新请求的结果，避免旧响应覆盖新筛选结果。`activeStation` 是前端展示状态，不改变后端的激活位置。

## Axios HTTP 配置

[`api/index.ts`](../frontend/src/api/index.ts) 创建 `baseURL='/api/v1'`、`timeout=30000` 的同源客户端，请求拦截器自动附加 Bearer token。响应拦截器返回 `response.data`；登录和注册以外的 401 会触发退出。

`health.ts` 独立请求同源 `/health`，超时 5 秒。DX Cluster 与 UDP 的 WebSocket 均使用页面所在的主机和协议；HTTPS 页面使用 `wss`。

Vite 将 `/api` 和 `/health` 转发到 `http://localhost:8000`，其中 `/api` 开启 `ws:true`。生产代理也必须提供这些路径。客户端不读取 `VITE_API_BASE_URL` 或 `RADIOMANAGER_API_URL`，目标后端由同源代理决定。

## 路由结构

| 路径 | 页面或行为 | 条件 |
| --- | --- | --- |
| `/` | 重定向 `/dashboard` | — |
| `/login`、`/register` | 登录、注册 | 已登录则进入仪表板 |
| `/dashboard` | 仪表板 | 登录 |
| `/logs`、`/logs/:id` | 列表、详情 | 登录 |
| `/stations`、`/callsigns` | 台站、呼号查询 | 登录 |
| `/dxclusters` | DX Cluster，注意使用复数路径 | 登录 |
| `/map`、`/tools` | 地图、工具箱 | 登录 |
| `/recycle`、`/shortcuts` | 回收站、快捷链接 | 登录 |
| `/analysis`、`/settings` | 分析、设置 | 登录 |
| `/admin/users`、`/admin/system`、`/admin/audit` | 管理页面 | MySQL 模式且为管理员 |
| 其他路径 | `NotFoundView` | — |

使用 `createWebHistory`。网页部署需要把非 API 的页面路径回退到 `index.html`，以支持刷新和直接访问详情页。

## 多语言支持（i18n）

`locales/index.ts` 使用 Composition API 模式。初始语言先读取 localStorage 的 `language`，再根据浏览器语言选择英文或中文；回退语言为 `en-US`。`setLanguage` 同时更新 locale 和本地语言设置。

主题工具 `utils/theme.ts` 保存 `light/dark/system` 到 `radiomanager-theme`，通过根元素 class 和 `data-theme` 应用样式；系统模式监听 `prefers-color-scheme`。主题属于本地偏好，不写入用户表。

## 构建与开发

以下命令在 `frontend/` 下运行：

```bash
npm ci
npm run dev          # Vite，默认 5173
npm run type-check   # vue-tsc --noEmit
npm run build        # Vite 构建到 dist/
npm run preview      # 预览静态构建，不提供后端 API
```

`build` 不包含类型检查。Electron 命令为 `electron`、`electron-dev`、`electron:win`、`electron:win-portable`、`electron:linux`、`electron:mac`；Android 命令为 `android:init`、`android:sync`、`android:open`、`android:build`。部署条件见 [Windows 与 Android 部署](09_Windows与Android部署.md)。
